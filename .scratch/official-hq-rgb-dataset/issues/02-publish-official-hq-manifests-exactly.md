# 02 — 原样发布官方 HQ 训练与测试清单

**What to build:** 让研究复现者生成与 Vislocas 官方训练集和测试集逐行一致的 HQ URL 清单。官方表是 HQ 归属的唯一权威，输出保留原始成员关系和相对顺序，不受补充数据或过时本地文件影响。

**Blocked by:** 01 — 锁定并校验 Vislocas 官方源数据

**Status:** done

- [x] HQ train 只从官方 `data_train.csv` 构建，HQ test 只从官方 `data_test.csv` 构建。
- [x] 每份 HQ 清单与对应官方表保持完全相同的行成员、行数和相对顺序。
- [x] 官方 HQ 行不会被重新分层、去重、降级、移动到另一侧或静默跳过，也不会从 `normalLabeled.csv` 重新推导。
- [x] 只按去除首尾空白后的 `Protein Id` 验证官方 train/test 不交叉；URL、文件名和图像内容不参与归属判断。
- [x] 每个 HQ 蛋白必须解析到唯一且非空的 reviewed sequence；缺失或歧义时整次 HQ 清单发布失败并报告对应源行。
- [x] 无法解析抗体编号、图像 URL 或其他下载必需字段的官方行会导致失败，不产生部分正式 HQ 清单。
- [x] 官方已占用源行以精确源行身份记录，供补充阶段排除；相同 URL 的其他合法源行不因此被排除。
- [x] CLI 级夹具测试证明官方行和顺序被原样保留，并证明历史本地 HQ 文件不会影响结果。
