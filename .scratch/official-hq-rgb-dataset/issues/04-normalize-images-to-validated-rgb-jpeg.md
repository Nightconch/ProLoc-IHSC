# 04 — 将图片规范化为经过复验的 RGB JPEG

**What to build:** 让下载流程把任意支持的源图片安全地产生为可重新打开的三通道 RGB JPEG，同时识别损坏图和全白图，并避免对已经合格的 JPEG 进行无意义的有损重编码。

**Blocked by:** None — can start immediately

**Status:** done

- [x] 可完整解码、格式为 JPEG、模式为 RGB、恰有三个通道且非全白的源图保留原始字节。
- [x] 灰度、调色板、CMYK 及其他无透明信息的有效图片转换为 JPEG RGB。
- [x] 具有 alpha 通道或透明信息的图片先与纯白背景合成，再转换为 JPEG RGB，透明区域不会变黑。
- [x] 图片转成最终 RGB 像素后，如果每个像素的三个通道值都不低于 250，则判定为全白并拒绝发布。
- [x] 截断内容、无法识别的格式和解码失败都会返回可分类的失败结果，不产生伪装成 JPEG 的文件。
- [x] 文件通过同目录临时文件和原子替换写入；写入后重新打开并确认格式为 JPEG、模式为 RGB、通道数为三且非全白。
- [x] 自动化测试使用小型本地图片覆盖合格 RGB JPEG、灰度、RGBA、CMYK、全白、阈值边界及损坏内容，并验证合格 JPEG 字节保持不变。
