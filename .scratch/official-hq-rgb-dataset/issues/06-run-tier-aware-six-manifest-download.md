# 06 — 按质量层级运行六清单下载与原子发布

**What to build:** 让操作者一次运行完整的 HQ/MQ/LQ train/test 下载，并得到符合各层失败策略的六份图片集合、六份正式训练 CSV 和统一审计报告。网络失败不会改变既定蛋白划分。

**Blocked by:** 03 — 发布无 Protein Id 泄漏的补充 MQ/LQ 清单；05 — 稳定下载单份清单并生成训练 CSV

**Status:** done

- [x] 六份清单在联网前完成结构、`Protein Id` 归属和全局文件名碰撞预检，问题被发现时不会留下新的正式产物。
- [x] HQ 的 sequence、URL、HTTP、下载、解码、全白、写盘或最终 RGB 复验任一失败都会使命令失败，并阻止新的正式 HQ CSV 发布。
- [x] HQ 全部成功时，train/test 的成功行数和顺序分别与官方清单完全一致。
- [x] MQ/LQ 的同类失败写入失败清单并跳过该行，命令继续处理其余记录；最终 CSV 仅含实际成功发布的图片并保留原相对顺序。
- [x] MQ/LQ 某个蛋白没有任何成功图片时，审计报告会按质量层级和 split 单独列出该蛋白。
- [x] 图片失败不会触发重新分层或改变任何 `Protein Id` 的既定 train/test 映射。
- [x] 六份正式 CSV 均使用固定九列契约，并通过临时产物和原子替换发布，异常中断不会暴露半成品 CSV。

- [x] 统一审计报告包含上游摘要、各层各 split 输入/成功/失败行数、失败明细、零成功蛋白以及最终 Protein Id 泄漏检查结果。
